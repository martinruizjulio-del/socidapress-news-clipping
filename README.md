# SocidaPress: News Clipping

Crea una aplicación que importe un archivo pdf.

El archivo ser una página completa en la que habrán fotos y texto de una noticia de periódico.

Tras importar la imagen el programa separará las fotos con respecto al texto y pedirá al usuario qué imagen o imágenes quiere conservar.

Se grabarán el nombre del periódico, el título de la noticia, la fecha y la hora.

El texto de la noticia se leerá por OCR y se transformará a texto plano.

Al igual que las imágenes, el usuario decidirá qué bloques de texto quiere conservar si hay más de uno

La aplicación se llamará SocidaPress
